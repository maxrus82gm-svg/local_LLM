# local_LLM — документация проекта Ultra LLM

**Основная документация:** [Documents/00_Старт.md](Documents/00_Старт.md). Новый чат обязан открыть и прочитать этот файл **не по памяти**, затем [Documents/000_Задачи для агента.md](Documents/000_Задачи%20для%20агента.md), [тактический контекст №13](Documents/13_Тактический_контекст.md) и [реестр №05](Documents/05_Реестр_задач.md).

**Рабочая ветка ChatGPT:** `GPT` — только в неё ChatGPT вносит, коммитит и пушит изменения. `main` — для решения/слияния владельца. Из GitHub работает обычное документное сопровождение, а Desktop Commander используется только по отдельному запросу.

**Локальный путь владельца:** `M:\GitHub\local_LLM\Documents`. **Сервер runtime отдельно:** `DESKTOP-KT4G5SM` → `C:\Server\Ultra_LLM` (`\\192.168.0.77\Server\Ultra_LLM` по SMB). Сервер продолжает выполнять Colibrì, хранить модели, конфигурации и техническое оснащение; GitHub не управляет runtime сам по себе. Прежняя серверная папка документации ждёт безопасной очистки после проверки зависимости `Colibri/ULTRA-CONTROL.py` от `Documents/Reports`.

Новая блочная система задач будет введена **отдельным решением владельца**, текущие задачи пока ведутся по существующему регламенту №000. Новые документы и связи Obsidian не создавать без отдельного разрешения. Веса, runtime, токены, секреты и пользовательские настройки не коммитить: репозиторий общедоступный.
