ULTRA LLM CLIENT — ПЕРЕНОСИМАЯ СБОРКА WINDOWS 64-bit (WEB-02)
============================================================

Эта папка содержит всю программу и встроенный Python runtime.
На конечном компьютере Python отдельно НЕ требуется.

ЗАПУСК
1. Скопируйте ВСЮ папку UltraLLM_Client_WEB02_Win64 на компьютер.
   Не переносите один EXE отдельно от папки _internal.
2. Дважды нажмите Install_Ultra_LLM_Client.vbs.
   На рабочем столе появится ярлык «Ultra LLM Client».
3. Нажмите ярлык — браузер откроет Web Client на 127.0.0.1.
   Вариант без установки ярлыка: Start_Ultra_LLM_Client.vbs.
4. Для завершения локального Web Client нажмите кнопку «Завершить Web Client».
   Это НЕ останавливает сервер Manager и модели.

НАСТРОЙКА ПЕРВОГО ПОДКЛЮЧЕНИЯ
1. В мастере введите имя и ID Manager, свой уникальный ID клиента,
   IP/DNS и HTTPS-порт. Например, 192.168.0.77 и 8443 (только LAN).
2. Получите публичный PEM-сертификат напрямую от доверенного
   администратора Manager и проверьте его отпечаток по отдельному каналу.
   Импортируйте сертификат в мастер.
3. Программа создаст собственный секретный токен в защищённом
   каталоге текущего пользователя. В браузер возвращается только SHA-256.
4. Передайте администратору Manager этот SHA-256, Client ID и свой
   клиентский IP. Администратор должен разрешить Client, модели/слоты и IP.
   До этого соединение может показывать 401/403/OFFLINE.
5. Повторите «Обновить». Настоящие данные появятся при успешном HTTPS.

ВАЖНО
* Не переносите файлы *.token и конфигурацию managers.json между ПК.
  На новом компьютере проходите регистрацию отдельно.
* Не отправляйте исходные токены, приватные TLS-ключи или свой личный
  конфиг в чат, GitHub, публичные файлообменники.
* Данные приложения — в %LOCALAPPDATA%\UltraLLM\Client, вне папки программы.
* Если перенесли папку на другой путь, запустите Install_Ultra_LLM_Client.vbs
  ещё раз: он обновит ТОЛЬКО собственный ярлык Ultra LLM Client.
* Вся локальная веб-часть работает на 127.0.0.1, не открывает LAN-порт.
  Менеджеры доступны через индивидуальные проверенные HTTPS-соединения.
* START/STOP, резервирование и автоматическое удобное подтверждение нового
  клиента на Manager пока ещё НЕ реализованы. Здесь есть честный мониторинг.
* Сборка пока не имеет цифровой подписи издателя; Windows может показать
  SmartScreen. Проверяйте источник пакета и SHA256SUMS.txt; не отключайте
  антивирус и не разрешайте файлы из неизвестных источников.
* Нужна Windows x64. Пока сборка реально испытана на Windows 11 x64; совместимость с другими компьютерами и версиями Windows проверяется отдельно.
* GitHub хранит исходники и сценарий сборки, но не ваши личные секреты.

Файлы:
 UltraLLMClient.exe            — основной оконный процесс без консоли
 _internal\                   — встроенный Python и веб-ресурсы
 Start_Ultra_LLM_Client.vbs    — запуск двойным щелчком
 Install_Ultra_LLM_Client.vbs  — создать ярлык на рабочем столе
 SHA256SUMS.txt                — проверки целостности каждого файла
