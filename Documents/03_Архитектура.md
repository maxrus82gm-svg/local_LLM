## Структура хранения

- `Base_LLM/Models/` — файлы локальных LLM-моделей.
- `Base_LLM/Data/` — рабочие данные и материалы проекта.
- `Base_LLM/Configs/` — конфигурации моделей и будущих компонентов.

## Компоненты

### Проверенная текущая связка (2026-11-01)
- **Машина исполнения:** Windows-сервер `DESKTOP-KT4G5SM`, корень `C:\Server\Ultra_LLM`; агенты Codex/Desktop читают и правят файлы через `\\192.168.0.77\Server\Ultra_LLM`. Запуск BAT с UNC на агентской машине **не запускает** Colibri на сервере.
- **Движок:** Colibri v2.1.0, исполняемый `qwen36.exe` в профиле пользователя сервера: `%LOCALAPPDATA%\colibri\runtime\colibri-v2.1.0\`. Python 3.12 используется для launcher/API. Upstream `START-HERE.bat` оставлен без изменений.
- **Модель:** `Base_LLM\Models\Qwen3-Coder-30B-A3B`; 49 файлов `model-*.safetensors`, около 19,39 млрд байт; в `config.json` тип `qwen3_moe`, 48 слоёв, 128 экспертов. Проверены структура и заголовки, **не полные хеши весов**.
- **Конфигурация Colibri:** `%LOCALAPPDATA%\colibri\setup.json` на сервере. Сохранённая подпись `Qwen3.6-35B-A3B` не соответствует фактической модели; это общее имя семейства `qwen36`, не свидетельство подмены весов. Собственный launcher закрепляет ID `qwen3-coder-30b-a3b-colibri`.
- **Контроллер Ultra:** `Colibri\ULTRA-START.bat`, `ULTRA-STOP.bat`, `ULTRA-STATUS.bat`, `ULTRA-CONTROL.py`, `ULTRA-README.md`. Запускать **локально на сервере** из `C:\Server\Ultra_LLM\Colibri` под пользователем, установившим Colibri; скрипты откажутся исполняться на другом имени машины.
- **Параметры последней подтверждённой сессии:** CUDA / RTX 3070 (8 GB), `--ram 12 --ctx 4096 --cap 32`. `--ram` — бюджет кэша/планировщика, не жёсткий предел процесса Windows. Серверный статус `ready`, `/health` 200, один движок и gateway; модель вручную ответила пользователю в браузере.

### Штатный порядок управления (только на сервере)

В PowerShell на `DESKTOP-KT4G5SM` под исходным пользователем Colibri:

```powershell
& "C:\Server\Ultra_LLM\Colibri\ULTRA-STATUS.bat"  # проверить состояние, не запускать модель
& "C:\Server\Ultra_LLM\Colibri\ULTRA-START.bat"   # запустить существующую модель без setup
& "C:\Server\Ultra_LLM\Colibri\ULTRA-STATUS.bat" --test  # по разрешению: два настоящих ответа
& "C:\Server\Ultra_LLM\Colibri\ULTRA-STOP.bat"    # штатная остановка по решению владельца
```

После готовности вручную открыть **на сервере** `http://127.0.0.1:8000/`. Само окно Ultra START может завершить ожидание, а фоновый supervisor продолжит работу. Контроль — через `ULTRA-STATUS.bat`, не по наличию видимого окна или иконки в трее. Перед остановкой/тестом учитывать других пользователей и активные процессы.

## Связи и интерфейсы

- Браузерный чат **на самом сервере**: `http://127.0.0.1:8000/`; API: `http://127.0.0.1:8000/v1`. IP `127.0.0.1` указывает на текущую машину, не на любой ПК сети. Доступ с клиентского ПК к серверному API пока не настраивался.
- У собственного `ULTRA-START.bat` **нет автоматического открытия браузера**. Это не означает, что API не стартовал; открывать адрес вручную. `ULTRA-STATUS.bat` показывает фактическую готовность.
- Управляемые процессы и журналы: `%LOCALAPPDATA%\colibri\ultra\` на сервере. Диагностика в общедоступной для агента папке `Documents\Reports\CODEX-ULTRA-LLM-COLIBRI-START-001\`; инструкция — `Colibri\ULTRA-README.md`.
- Для остановки применять `ULTRA-STOP.bat` на сервере. Не завершать чужие процессы `python.exe` и не применять `--force-orphans` без адресной диагностики и явного решения.

## Переносимость

- Сетевой путь `\\192.168.0.77\Server\Ultra_LLM` и имя машины временные; в будущих TASK указывать отдельно SMB-доступ агента и локальный серверный runtime. `setup.json` и исполняемый runtime находятся вне сетевой папки проекта.
- Существующий скрипт привязан к текущему имени сервера и его модели. Для переноса нужны проверка путей, адаптация guard и отдельный серверный тест, а не простое копирование BAT.
- **Границы доказанного:** локальные тесты контроллера Codex 28/28; серверная диагностика и запуск Qwen подтверждены. Автоматический формальный тест двух ответов со скоростью токенов/с, устойчивость истории диалога и независимая продуктовая приёмка — `NOT VERIFIED`. Подробности в `09_История_задач.md` → `CODEX-ULTRA-LLM-COLIBRI-START-001`.
