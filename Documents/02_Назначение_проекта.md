## Назначение Ultra LLM

Организация локальных LLM-моделей, рабочих данных и конфигураций для последующего развёртывания на сервере.

## Принципы проекта

1. Ultra LLM — самостоятельный проект.
2. Web Alarm Ultra остаётся отдельной системой.
3. Интеграция с Web Alarm Ultra возможна в будущем; сейчас она не реализована.
4. Локальные модели и пользовательские данные хранятся раздельно.
5. Архитектура должна допускать перенос на другой компьютер.
6. Будущие программные конфигурации не должны содержать жёсткие машинные пути.
7. Новые функции и задачи требуют отдельного согласования с владельцем.
8. Codex и Claude выполняют отдельные назначенные задачи. ChatGPT координирует работу и проводит независимую проверку.
9. Отчёты сохраняются в файлах.
10. Самопроверка исполнителя не считается независимой приёмкой.
