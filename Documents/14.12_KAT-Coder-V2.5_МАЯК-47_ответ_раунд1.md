

# МАЯК-47 — Система взаимодействия с интерактивной лампой

## ЭТАП 1. АРХИТЕКТУРА

### Необходимые классы

| Класс | Роль |
|---|---|
| `IInteractiveObject` | C++ интерфейс (`UNINTERFACE`) — контракт «можно взаимодействовать» |
| `AInteractiveLamp` | `Actor`, реализующий `IInteractiveObject` — лампа со светом и мешем |
| `AInteractionLabCharacter` | `Character`, выполняющий Line Trace и обрабатывающий ввод |

### Как они взаимодействуют

```
Ввод (Enhanced Input)
        │
        ▼
AInteractionLabCharacter::OnInteract()
        │
        │  LineTrace (425 см, по направлению камеры)
        ▼
   HitActor?  ──► Нет → ничего
        │
       Да
        │
        ▼
   Cast<IInteractiveObject>()?
        │
       Да
        │
        ▼
   Lamp->ToggleLight()
   (с cooldown 0.35s)
```

### Обработка нажатия E
Через **Enhanced Input**: действие `Interact` (Action) привязано к клавише `E`. При срабатывании вызывается `OnInteract()` на персонаже.

### Определение объекта
`LineTraceSingleByChannel` из камеры (или из корневой точки персонажа, смотрящей по forward) с `TraceComplex`, канал `ECC_Visibility`. Полученный `HitActor` проверяется на реализацию `IInteractiveObject`.

### Ограничение частоты
В `AInteractiveLamp` — поле `float LastToggleTime = 0.f`. В `ToggleLight()` проверяется `GetWorld()->GetTimeSeconds() - LastToggleTime >= 0.35f`. Если прошло менее 0.35 с — выход.

#include "CoreMinimal.h"

// Интерфейс для объектов, с которыми можно взаимодействовать.
// Реализуется на AInteractiveLamp.

class INTERACTIONLAB_API IInteractiveObject
{
    GENERATED_BODY()

public:
    // Переключает состояние взаимодействия (вкл/выкл свет и т.д.).
    // Возвращает true, если взаимодействие успешно выполнено.

    bool ToggleInteraction();
};

### InteractiveLamp.h

```cpp
#pragma once

#include "CoreMinimal.h"
#include "GameFramework/Actor.h"
#include "IInteractiveObject.h"
#include "InteractiveLamp.h"
#include "InteractiveLamp.generated.h"

UCLASS()
class INTERACTIONLAB_API AInteractiveLamp : public AActor, public IInteractiveObject
{
    GENERATED_BODY()

public:
    AInteractiveLamp();

protected:
    virtual void BeginPlay() override;

public:
    virtual bool ToggleInteraction_Implementation() override;

private:
    // Визуальный меш лампы.
    UPROPERTY(VisibleDefaultsOnly, Category = "Lamp")
    UStaticMeshComponent* LightMesh;

    // Источник света, смещённый на 35 см выше меша по локальной оси Z.
    UPROPERTY(VisibleDefaultsOnly, Category = "Lamp")
    UPointLightComponent* LightSource;

    // Флаг текущего состояния света.
    UPROPERTY(Transient)
    bool bIsLightOn;

    // Время последнего переключения (GetWorld()->GetTimeSeconds()).
    UPROPERTY(Transient)
    float LastToggleTime;

    // Минимальный интервал между взаимодействиями (сек).
    static constexpr float MinToggleInterval = 0.35f;
};
```

### InteractiveLamp.cpp

```cpp
#include "InteractiveLamp.h"
#include "Components/StaticMeshComponent.h"
#include "Components/PointLightComponent.h"

AInteractiveLamp::AInteractiveLamp()
{
    PrimaryActorTick.bCanEverTick = false;

    // Корневой компонент — меш лампы.
    LightMesh = CreateDefaultSubobject<UStaticMeshComponent>(TEXT("LightMesh"));
    RootComponent = LightMesh;

    // Источник света — на 35 см выше меша по локальной оси Z.
    LightSource = CreateDefaultSubobject<UPointLightComponent>(TEXT("LightSource"));
    LightSource->SetupAttachment(RootComponent);
    LightSource->SetRelativeLocation(FVector(0.f, 0.f, 35.f));

    // Первоначально свет включён.
    bIsLightOn = true;
    LightSource->SetVisibility(true);

    LastToggleTime = 0.f;
}

void AInteractiveLamp::BeginPlay()
{
    Super::BeginPlay();
    ToggleInteraction_Implementation(); // начальная синхронизация состояния
}

bool AInteractiveLamp::ToggleInteraction_Implementation()
{
    const float CurrentTime = GetWorld() ? GetWorld()->GetTimeSeconds() : 0.f;
    if (CurrentTime - LastToggleTime < MinToggleInterval)
    {
        return false;
    }

    bIsLightOn = !bIsLightOn;
    LightSource->SetVisibility(bIsLightOn);
    LastToggleTime = CurrentTime;
    return true;
}
```

### InteractionLabCharacter.h

```cpp
#pragma once

#include "CoreMinimal.h"
#include "GameFramework/Character.h"
#include "InputActionValue.h"
#include "IInteractiveObject.h"
#include "InteractionLabCharacter.h"
#include "InteractionLabCharacter.generated.h"

class UInputMappingContext;
class UInputAction;

UCLASS()
class INTERACTIONLAB_API AInteractionLabCharacter : public ACharacter
{
    GENERATED_BODY()

public:
    AInteractionLabCharacter();

protected:
    virtual void BeginPlay() override;
    virtual void SetupPlayerInputComponent(UInputComponent* PlayerInputComponent) override;

    // Enhanced Input: обработка действия Interact.
    UFUNCTION()
    void OnInteract(const FInputActionValue& ActionValue);

private:
    // Mapping Context и Action, настраиваемые в конструкторе через DefaultInput.
    UPROPERTY(EditDefaultsOnly, Category = "Input")
    UInputMappingContext* DefaultMappingContext;

    UPROPERTY(EditDefaultsOnly, Category = "Input")
    UInputAction* InteractAction;

    // Попытка взаимодействовать с ближайшим объектом в направлении взгляда.
    void TryInteract();

    // Максимальная дистанция взаимодействия — 425 см.
    static constexpr float InteractionMaxDistance = 425.f;
};
```

### InteractionLabCharacter.cpp

```cpp
#include "InteractionLabCharacter.h"
#include "InteractiveLamp.h"
#include "Camera/CameraComponent.h"
#include "GameFramework/PlayerController.h"
#include "InputAction.h"
#include "InputMappingContext.h"
#include "Engine/World.h"

AInteractionLabCharacter::AInteractionLabCharacter()
{
    PrimaryActorTick.bCanEverTick = false;

    // Камера от первого лица — источник направления Line Trace.
    CameraComponent = CreateDefaultSubobject<UCameraComponent>(TEXT("FirstPersonCamera"));
    CameraComponent->SetupAttachment(GetCapsuleComponent());
    CameraComponent->bUsePawnControlRotation = true;

    InteractAction = CreateDefaultSubobject<UInputAction>(TEXT("InteractAction"));
}

void AInteractionLabCharacter::BeginPlay()
{
    Super::BeginPlay();

    if (APlayerController* PC = Cast<APlayerController>(GetController()))
    {
        if (UWorld* World = GetWorld())
        {
            if (UInputMappingContext* MC = DefaultMappingContext)
            {
                PC->AddInputMappingContext(MC);
            }
            if (InteractAction)
            {
                PC->AddInputContext(InteractAction); // контекст уже добавлен через MC;
                                                     // это гарантирует наличие биндинга
            }
        }
    }
}

void AInteractionLabCharacter::SetupPlayerInputComponent(UInputComponent* PlayerInputComponent)
{
    Super::SetupPlayerInputComponent(PlayerInputComponent);

    if (UEnhancedInputComponent* EnhancedComp = Cast<UEnhancedInputComponent>(PlayerInputComponent))
    {
        if (InteractAction)
        {
            EnhancedComp->BindAction(InteractAction, ETriggerEvent::Completed, this,
                &AInteractionLabCharacter::OnInteract);
        }
    }
}

void AInteractionLabCharacter::OnInteract(const FInputActionValue& ActionValue)
{
    TryInteract();
}

void AInteractionLabCharacter::TryInteract()
{
    UWorld* World = GetWorld();
    if (!World) return;

    APlayerController* PC = Cast<APlayerController>(GetController());
    if (!PC) return;

    // Получаем позицию и направление камеры.
    FVector CamLoc;
    FRotator CamRot;
    CameraComponent->GetWorldTransform().GetLocationAndRotation(CamLoc, CamRot);

    FVector Start = CamLoc;
    FVector Direction = CamRot.Vector();
    FVector End = Start + Direction * InteractionMaxDistance;

    FHitResult Hit;
    FCollisionQueryParams Params(TEXT("InteractionTrace"), true, this);
    Params.bReturnPhysicalMaterial = false;

    bool bHit = World->LineTraceSingleByChannel(Hit, Start, End, ECC_Visibility, Params);

    if (!bHit || !Hit.GetActor()) return;

    // Проверяем, реализует ли хитовый актёр интерфейс IInteractiveObject.
    IInteractiveObject* Interactive =
        Cast<IInteractiveObject>(Hit.GetActor());
    if (!Interactive) return;

    Interactive->ToggleInteraction();
}
```

## Настройка Enhanced Input в редакторе

1. **Create → Input → Input Mapping Context** → `IMC_InteractionLab`
2. Добавьте в него **Input Action** `IA_Interact` (Trigger Event: `Completed`)
3. Откройте `Project Settings → Engine → Input` → добавьте `IMC_InteractionLab` в **Default Map**
4. В **Bindings** привяжите клавишу `E` к `IA_Interact`
5. В **Character Blueprint / DefaultActor** заполните `DefaultMappingContext` и `InteractAction` ссылками на созданные объекты

### 3.3 Проверка Enhanced Input

- `UInputMappingContext` и `UInputAction` — корректные типы из `EnhancedInput`.
- `BindAction(..., ETriggerEvent::Completed, ...)` — корректно.
- `UEnhancedInputComponent::Cast` — стандартный паттерн.

**Замечание:** в `BeginPlay` вызов `PC->AddInputContext(InteractAction)` избыточен — контекст добавляется через `AddInputMappingContext`. Уберём.

**Исправление InteractionLabCharacter.cpp — BeginPlay:**

```cpp
void AInteractionLabCharacter::BeginPlay()
{
    Super::BeginPlay();

    if (APlayerController* PC = Cast<APlayerController>(GetController()))
    {
        if (UWorld* World = GetWorld() && DefaultMappingContext)
        {
            PC->AddInputMappingContext(DefaultMappingContext);
        }
    }
}
```

### 3.4 Проверка Line Trace

- `LineTraceSingleByChannel` — корректный API UE5.
- Канал `ECC_Visibility` — корректен для обнаружения объектов.
- `Params.bReturnPhysicalMaterial = false` — опционально, не влияет.
- Направление берётся из `CameraComponent->GetWorldTransform().GetLocationAndRotation` — корректно.

**Замечание:** `GetWorldTransform()` возвращает `FTransform`, у которого нет метода `GetLocationAndRotation` — это метод `FTransform` из UE4, в UE5 используется `GetLocation()` и `GetRotation()` или `GetComponentLocation()` / `GetComponentRotation()`. Исправим.

**Исправление TryInteract:**

```cpp
void AInteractionLabCharacter::TryInteract()
{
    UWorld* World = GetWorld();
    if (!World) return;

    APlayerController* PC = Cast<APlayerController>(GetController());
    if (!PC) return;

    FVector Start = CameraComponent->GetComponentLocation();
    FRotator CamRot = CameraComponent->GetComponentRotation();
    FVector Direction = CamRot.Vector();
    FVector End = Start + Direction * InteractionMaxDistance;

    FHitResult Hit;
    FCollisionQueryParams Params(TEXT("InteractionTrace"), true, this);

    bool bHit = World->LineTraceSingleByChannel(Hit, Start, End, ECC_Visibility, Params);

    if (!bHit || !Hit.GetActor()) return;

    IInteractiveObject* Interactive =
        Cast<IInteractiveObject>(Hit.GetActor());
    if (!Interactive) return;

    Interactive->ToggleInteraction();
}
```
