# Ultra LLM

**Инструкция владельца:** [[23_Подключение и настройка Client, Manager и VPN]] — соединение Client и Manager, VPN и карта настроек.

**Состояние: документация и локальный Colibrì развиваются. Действующие запуски и результаты проверок сверять с `13_Тактический_контекст.md`; один запуск модели не означает завершённой инженерной приёмки.**

Ultra LLM — самостоятельный проект для организации локальных LLM-моделей, их данных и конфигураций с последующим развёртыванием на сервере.

## Расположение

- **Основная база документации:** `https://github.com/maxrus82gm-svg/local_LLM` → `Documents/`; локальный Git-клон `M:\GitHub\local_LLM\Documents`.
- **Ветка ChatGPT:** `GPT_2_local` (ChatGPT публикует только по прямому поручению владельца); `main` обновляет владелец после проверки.
- **Исполняемый сервер (отдельно):** `DESKTOP-KT4G5SM` → `C:\Server\Ultra_LLM`, через SMB `\\192.168.0.77\Server\Ultra_LLM`.
- **Серверные веса/данные/конфигурации:** `Base_LLM/Models/`, `Base_LLM/Data/`, `Base_LLM/Configs/`. Модели, runtime и серверные логи не переносятся в GitHub.

## Текущее состояние

На HOME и Server77 имеются действующие Manager и проверенные пользовательские сценарии работы локальных CPU/CUDA-моделей; WORK и дальнейшие проверки — по фактическим доказательствам в №13/18. Видимый бренд Client — «Неополис». Интеграция со Студией через Bridge v1 ещё не принята в полном объёме: WEB35 готовит подключение, реальные результаты проверяются отдельно. WireGuard HOME↔WORK пока не принят. Актуальный статус CI, установленных версий и задач — [[13_Тактический_контекст]].

## Следующее согласование

Сначала сверить текущий handoff WEB35 и общий локальный план №34.1/34.1.1. Новые задачи не активировать автоматически. Для настройки подключения использовать №23; будущий UI сети и доступа согласуется отдельно.
