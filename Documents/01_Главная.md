# Ultra LLM

**Состояние: документация и локальный Colibrì развиваются. Действующие запуски и результаты проверок сверять с `13_Тактический_контекст.md`; один запуск модели не означает завершённой инженерной приёмки.**

Ultra LLM — самостоятельный проект для организации локальных LLM-моделей, их данных и конфигураций с последующим развёртыванием на сервере.

## Расположение

- **Основная база документации:** `https://github.com/maxrus82gm-svg/local_LLM` → `Documents/`; локальный Git-клон `M:\GitHub\local_LLM\Documents`.
- **Ветка ChatGPT:** `GPT` (только commit/push сюда); `main` обновляет владелец после проверки.
- **Исполняемый сервер (отдельно):** `DESKTOP-KT4G5SM` → `C:\Server\Ultra_LLM`, через SMB `\\192.168.0.77\Server\Ultra_LLM`.
- **Серверные веса/данные/конфигурации:** `Base_LLM/Models/`, `Base_LLM/Data/`, `Base_LLM/Configs/`. Модели, runtime и серверные логи не переносятся в GitHub.
