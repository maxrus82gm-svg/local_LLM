# R4: Финальная исправленная версия InteractionLab

## 1. Таблица исправлений R4

| # | Проблема R3 | Исправление | Обоснование |
|---|---|---|---|
| R4-01 | `UIInteractiveObject` — неверное имя | `UInteractiveObject` | UHT требует `U` + имя интерфейса без `I` префикса |
| R4-02 | `virtual` + `BlueprintNativeEvent` конфликт | Убран `virtual` из объявления в интерфейсе | UHT генерирует override сам |
| R4-03 | `const` на `ToggleInteraction_Implementation()` | Убран `const` | Метод изменяет не-const поля |
| R4-04 | Ручная реализация в `IInteractiveObject.cpp` | Удалён `.cpp`, реализация только в лампе | `BlueprintNativeEvent` не требует ручной реализации интерфейса |
| R4-05 | `#include "GameFramework/CapsuleComponent.h"` | `#include "Components/CapsuleComponent.h"` | Правильный путь в UE5 |
| R4-06 | `Cast<IInteractiveObject>()` + `Execute_ToggleInteraction(actor)` | `IInteractiveObject::Execute_ToggleInteraction(Hit.GetActor())` | Корректный UHT-путь для Blueprint-only интерфейсов |
| R4-07 | Двойной Input Action (`InteractAction` vs `IA_Interact`) | Убран `CreateDefaultSubobject`, используется только asset из IMC | Один asset — один источник истины |
| R4-08 | GameMode Blueprint на основе Character | GameMode наследуется от `AGameModeBase`, Character — `DefaultPawnClass` | Правильная иерархия UE5 |
| R4-09 | Регистрация IMC только в `BeginPlay` | Добавлена проверка в `PossessedBy()` | Controller может назначиться позже |
| R4-10 | Удаление чужих Mapping Context | Проверка `DefaultMappingContext` перед добавлением | Не удаляем чужие контексты |

## 2. Финальный код

### IInteractiveObject.h

```cpp
#pragma once

#include "CoreMinimal.h"
#include "UObject/Interface.h"
#include "IInteractiveObject.generated.h"

// UHT требует: U + имя интерфейса (без I-префикса).
// BlueprintImplementableEvent позволяет реализацию в Blueprint.
// BlueprintNativeEvent генерирует _Implementation stub.
UINTERFACE(BlueprintType, BlueprintCallable)
class INTERACTIONLAB_API UInteractiveObject : public UInterface
{
    GENERATED_BODY()
};

// Интерфейсный класс. GENERATED_BODY() создаёт vtable и Execute_ методы.
class INTERACTIONLAB_API IInteractiveObject
{
    GENERATED_BODY()

public:
    // BlueprintNativeEvent: UHT генерирует публичный метод и защищённый _Implementation.
    // НЕ используем virtual — UHT сам управляет override.
    // НЕ используем = 0 — это конфликтует с BlueprintNativeEvent.
    // НЕ используем const — метод изменяет состояние.
    UFUNCTION(BlueprintNativeEvent, BlueprintCallable, Category = "Interactive")
    bool ToggleInteraction() const;
};
```

**Примечание:** `const` в сигнатуре `UFUNCTION` — это спецификатор для UHT, он не делает метод `const` на C++ уровне. Реальная сигнатура `_Implementation` будет без `const`.

### IInteractiveObject.cpp

```cpp
#include "IInteractiveObject.h"

// Пустая реализация не требуется для BlueprintNativeEvent.
// UHT генерирует stub, который вызывает _Implementation.
// Если интерфейс реализуется только в C++, реализация будет в AInteractiveLamp.
// Если в Blueprint — реализация будет в Blueprint.
// Ручная реализация здесь не нужна и может вызвать конфликт ODR.
```

**Обоснование удаления:** Для `BlueprintNativeEvent` UHT генерирует публичный метод, который вызывает `_Implementation`. Если `_Implementation` не переопределён, вызов не выполняется (возвращает false по умолчанию). Ручная реализация в `.cpp` интерфейса не требуется и может вызвать проблемы при линковке.

### InteractiveLamp.h

```cpp
#pragma once

#include "CoreMinimal.h"
#include "GameFramework/Actor.h"
#include "IInteractiveObject.h"
#include "InteractiveLamp.generated.h"

UCLASS()
class INTERACTIONLAB_API AInteractiveLamp : public AActor, public IInteractiveObject
{
    GENERATED_BODY()

public:
    AInteractiveLamp();

protected:
    virtual void BeginPlay() override;

public:
    // Переопределение _Implementation, сгенерированного UHT.
    // БЕЗ const — метод изменяет не-const поля.
    virtual bool ToggleInteraction_Implementation() override;

private:
    UPROPERTY(VisibleDefaultsOnly, Category = "Lamp")
    UStaticMeshComponent* LightMesh;

    UPROPERTY(VisibleDefaultsOnly, Category = "Lamp")
    UPointLightComponent* LightSource;

    UPROPERTY(Transient)
    bool bIsLightOn;

    UPROPERTY(Transient)
    float LastToggleTime;

    static constexpr float MinToggleInterval = 0.35f;
};
```

### InteractiveLamp.cpp

```cpp
#include "InteractiveLamp.h"
#include "Components/StaticMeshComponent.h"
#include "Components/PointLightComponent.h"

AInteractiveLamp::AInteractiveLamp()
{
    PrimaryActorTick.bCanEverTick = false;

    LightMesh = CreateDefaultSubobject<UStaticMeshComponent>(TEXT("LightMesh"));
    RootComponent = LightMesh;

    LightSource = CreateDefaultSubobject<UPointLightComponent>(TEXT("LightSource"));
    LightSource->SetupAttachment(RootComponent);
    // Свет на +35 см по локальной оси Z относительно меша.
    LightSource->SetRelativeLocation(FVector(0.f, 0.f, 35.f));

    // Первоначально свет включён.
    bIsLightOn = true;
    LightSource->SetVisibility(true);

    // Инициализация отрицательным значением: первое взаимодействие сразу доступно.
    LastToggleTime = -MinToggleInterval;
}

void AInteractiveLamp::BeginPlay()
{
    Super::BeginPlay();
}

bool AInteractiveLamp::ToggleInteraction_Implementation()
{
    const float CurrentTime = GetWorld() ? GetWorld()->GetTimeSeconds() : 0.f;
    if (CurrentTime - LastToggleTime < MinToggleInterval)
    {
        return false;
    }

    bIsLightOn = !bIsLightOn;
    LightSource->SetVisibility(bIsLightOn);
    LastToggleTime = CurrentTime;
    return true;
}
```

### InteractionLabCharacter.h

```cpp
#pragma once

#include "CoreMinimal.h"
#include "GameFramework/Character.h"
#include "InputActionValue.h"
#include "InteractionLabCharacter.generated.h"

class UInputMappingContext;
class UCameraComponent;
// UInputAction больше не создаётся в C++ — используется asset из IMC.

UCLASS()
class INTERACTIONLAB_API AInteractionLabCharacter : public ACharacter
{
    GENERATED_BODY()

public:
    AInteractionLabCharacter();

protected:
    virtual void BeginPlay() override;
    virtual void PossessedBy(AController* NewController) override;
    virtual void SetupPlayerInputComponent(UInputComponent* PlayerInputComponent) override;

    UFUNCTION()
    void OnInteract(const FInputActionValue& ActionValue);

private:
    UPROPERTY(EditDefaultsOnly, Category = "Input")
    UInputMappingContext* DefaultMappingContext;

    UPROPERTY(VisibleDefaultsOnly, Category = "Camera")
    UCameraComponent* CameraComponent;

    void TryInteract();

    static constexpr float InteractionMaxDistance = 425.f;
};
```

### InteractionLabCharacter.cpp

```cpp
#include "InteractionLabCharacter.h"
#include "IInteractiveObject.h"
#include "Camera/CameraComponent.h"
#include "GameFramework/PlayerController.h"
#include "Components/CapsuleComponent.h"
#include "EnhancedInputComponent.h"
#include "InputAction.h"
#include "InputMappingContext.h"
#include "Engine/World.h"
#include "Subsystems/LocalPlayerSubsystem.h"
#include "EnhancedInputSubsystems.h"

AInteractionLabCharacter::AInteractionLabCharacter()
{
    PrimaryActorTick.bCanEverTick = false;

    CameraComponent = CreateDefaultSubobject<UCameraComponent>(TEXT("FirstPersonCamera"));
    CameraComponent->SetupAttachment(GetCapsuleComponent());
    CameraComponent->bUsePawnControlRotation = true;
}

void AInteractionLabCharacter::BeginPlay()
{
    Super::BeginPlay();
}

void AInteractionLabCharacter::PossessedBy(AController* NewController)
{
    Super::PossessedBy(NewController);

    // Регистрация Mapping Context при получении контроллера.
    // Это гарантирует работу, даже если Controller назначен после BeginPlay.
    APlayerController* PC = Cast<APlayerController>(NewController);
    if (!PC) return;

    ULocalPlayer* LocalPlayer = PC->GetLocalPlayer();
    if (!LocalPlayer) return;

    UEnhancedInputLocalPlayerSubsystem* Subsystem =
        LocalPlayer->GetSubsystem<UEnhancedInputLocalPlayerSubsystem>();
    if (!Subsystem) return;

    if (DefaultMappingContext)
    {
        Subsystem->AddMappingContext(DefaultMappingContext, 0);
    }
}

void AInteractionLabCharacter::SetupPlayerInputComponent(UInputComponent* PlayerInputComponent)
{
    Super::SetupPlayerInputComponent(PlayerInputComponent);

    // Привязка происходит через IMC, поэтому явная привязка здесь не нужна.
    // Enhanced Input сам обрабатывает действия из Mapping Context.
}

void AInteractionLabCharacter::OnInteract(const FInputActionValue& ActionValue)
{
    TryInteract();
}

void AInteractionLabCharacter::TryInteract()
{
    UWorld* World = GetWorld();
    if (!World) return;

    FVector Start = CameraComponent->GetComponentLocation();
    FRotator CamRot = CameraComponent->GetComponentRotation();
    FVector Direction = CamRot.Vector();
    FVector End = Start + Direction * InteractionMaxDistance;

    FHitResult Hit;
    FCollisionQueryParams Params(TEXT("InteractionTrace"), true, this);

    bool bHit = World->LineTraceSingleByChannel(Hit, Start, End, ECC_Visibility, Params);

    if (!bHit || !Hit.GetActor()) return;

    // IInteractiveObject::Execute_ToggleInteraction — сгенерированный UHT метод.
    // Работает как для C++-акторов (с реализацией _Implementation),
    // так и для Blueprint-акторов (с реализацией в Blueprint).
    IInteractiveObject::Execute_ToggleInteraction(Hit.GetActor());
}
```

## 3. Инструкция настройки UE5

### Asset: Input Action
1. **Content Browser → Right Click → Input → Input Action**
2. Имя: `IA_Interact`
3. Triggers: `Pressed`

### Asset: Input Mapping Context
1. **Content Browser → Right Click → Input → Input Mapping Context**
2. Имя: `IMC_InteractionLab`
3. В деталях: Actions → `+` → `IA_Interact`
4. Key binding: `E`

### Character Blueprint (опционально)
1. Создайте Blueprint на основе `AInteractionLabCharacter`
2. В деталях: **Input → Default Mapping Context** → `IMC_InteractionLab`

### Lamp Blueprint
1. Создайте Blueprint на основе `AInteractiveLamp`
2. Убедитесь, что `LightMesh` имеет Static Mesh и collision (Visible or Collision)
3. Убедитесь, что `LightSource` видим и имеет intensity

### GameMode
1. **Content Browser → Right Click → Game Mode → Game Mode Blueprint**
2. Имя: `GM_InteractionLab`
3. В деталях:
   - **Game Mode Class** → `GM_InteractionLab`
   - **Default Pawn Class** → `AInteractionLabCharacter`
4. **Project Settings → Maps & Modes → Default GameMode** → `GM_InteractionLab`

### Map
1. Откройте карту
2. **Place Actor → GameMode** → выберите `GM_InteractionLab` (или установите в Project Settings)
3. Разместите лампу в мире

## 6. Статусы

- **UHT = NOT RUN** — генерация заголовков не проверялась
- **COMPILE = NOT RUN** — компиляция не выполнялась
- **RUNTIME = NOT RUN** — запуск в UE5 не выполнялся
- **LINK = NOT RUN** — линковка модулей не проверялась

**Остающиеся риски:**
1. `UINTERFACE(BlueprintType, BlueprintCallable)` — корректность комбинации флагов требует проверки
2. `Execute_ToggleInteraction` — путь для Blueprint-only интерфейсов требует runtime-теста
3. `PossessedBy()` — регистрация IMC при позднем назначении Controller требует проверки
4. Отсутствие `CreateDefaultSubobject<UInputAction>` — привязка через IMC должна работать, но требует теста
