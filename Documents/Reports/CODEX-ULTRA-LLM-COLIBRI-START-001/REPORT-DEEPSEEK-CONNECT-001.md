## PROBLEMS

- Реальный запуск DeepSeek, работа её GPU backend, два последовательных ответа и скорость пока НЕ проверены. Файлов REAL-GENERATION-TESTS*.json на момент отчёта нет; у Qwen два ответа из исходного задания также остаются неподтверждёнными.
- Доступ с домашнего ПК позволяет читать/писать файлы по SMB, но не выполнять серверные команды. API привязан к 127.0.0.1 сервера. Проверка запуска должна выполняться локально на DESKTOP-KT4G5SM под пользователем silver. Защита BAT специально запрещает запуск движка на домашнем ПК.
- Наличие DeepSeek EXE и generic DLL в приватном серверном runtime не подтверждено чтением из домашнего ПК. Их наличие проверяется перед остановкой Qwen; при отсутствии будет отказ, без скачивания/переустановки. STATUS публикует available_profiles.
- Все веса DeepSeek одновременно в RAM/VRAM не помещаются; используется дисковая подгрузка экспертов. Реальная скорость неизвестна. Первая загрузка/прогрев могут превысить 600 секунд; timeout не считается успехом, наблюдение supervisor продолжается.
- Если новый движок не загрузится после корректной остановки старого, автоматического возврата нет; выберите Qwen повторно.
